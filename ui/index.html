STEP 1 · 配置供应商

先喂饱数据源

没有供应商，仪表盘就是一块空屏。三步接通第一个额度源：

  1. 01
    左侧导航切到「供应商」页
    所有额度源都在这里统一管理。
  2. 02
    点「＋ 添加供应商」，选类型
    DeepSeek / Kimi / OpenRouter / opencode-go…… 13 种预设，余额型 / 中转站 / 订阅配额自动适配显示形态。
  3. 03
    填凭据（API Key / Cookie），保存即启用
    凭据存在本机，加密保管，只有你能看到。
没有 Key？把「演示模式」开关打开，不用 Key 也有模拟数据，先看界面再补凭据。

STEP 2 · 验证与接管

看它活过来

配置完成后，三件事依次发生：

  1. ✓
    测试连接 —— 供应商页点「测试连接」，延迟数字蹦出来就是通了。
  2. ✓
    数据上屏 —— 仪表盘出现余额卡 / 进度条，7 日趋势开始爬坡。
  3. ✓
    自动接管 —— 迷你窗实时悬浮，80% / 95% 两级阈值，超额之前先提醒你。
数据会说话。别让额度静悄悄烧光。
