STEP 2 · 配置

三步接好供应商

在「供应商」页，从 13 种预设里挑一个。

  1. 01
    添加供应商
    选类型，余额型 / 中转站 / 订阅自动适配显示。
  2. 02
    填 API Key
    凭据加密存本机，只有你能看到。
  3. 03
    保存即启用
    供应商卡片亮起，开始抓数据。

STEP 5 · 进阶

对话助手也能配

不想手动填？让对话助手（agent）代劳。

对话助手 在 Hana 里直接说：
「给 OC-GO 添加一个 DeepSeek 供应商」
它会调 cli.py 帮你配好，软件自动重载。
也可以在项目目录手动跑命令，--api-key - 表示从 stdin 读，不留在命令行里。
$ python cli.py add deepseek-main --type deepseek \
    --name "DeepSeek" --api-key sk-****
✓ 已添加供应商 'deepseek-main'
  运行中的软件将自动重载
$ python cli.py list
deepseek-main  DeepSeek  type=deepseek  enabled ✓
